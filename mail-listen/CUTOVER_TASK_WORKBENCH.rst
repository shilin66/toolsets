割接任务详情：运营工作台
======================

范围
----

仅调整邮件任务详情页，任务列表、现有查询条件和返回时的列表状态保持原样。
面向 1280px 及以上桌面宽度，不涉及 FastGPT 工作流和后端业务判定调整。

操作方式
--------

* 邮件核对：左侧显示经过安全过滤的原邮件和附件，右侧核对时间、原因、地点和运营商单号。
  「编辑识别结果」使用业务表单；固定字段和实际线路字段可修改，线路 key 与编号前导零保留。
  起止时间复用项目通用日期时间选择器，按识别时区填写并保留秒精度；空值或结束早于开始时阻止保存。
  JSON 原始编辑器收进「高级信息」。识别结果下方列出线路，自定义 key 排在固定字段之前。
  标为已读、高级信息和删除操作直接显示在页头按钮栏。
* 线路确认：直接列出全部线路，保留已匹配、未匹配、多条匹配、人工绑定等状态标签及统计。
  使用原有线路绑定与重新生成接口，按邮件中的线路顺序展示，不再提供状态切换。
* 回复审核：保留收件人、抄送、正文、发送确认和放弃回复；切换页签保留正在编辑的回复。
  发送成功后按时间倒序展示回复记录，保留实际收件人、抄送、发送时间与正文；后续草稿不覆盖已发送记录。
  历史记录只展示已保存的信息，未保存的实际地址显示「未记录」。更新后需重启后端以加载接口并补齐数据库字段。
* 上报处理：客户与骨干任务分别展示，核对已保存的线路、时间、影响和原因。
  完整填报表单可展开；保留保存、人工确认、综调上报、执行进度、失败原因和操作截图。
  骨干上报仅上传来源邮件的原始 EML，不单独上传邮件附件。点击上报后立即显示准备进度，
  登录检查及任务创建期间禁用重复上报；创建失败后显示原因并允许重试。
  骨干填报的关联变更与附件上传步骤在截图前定位到对应表单区域，避免选项已选中或隐藏上传控件
  导致画面停留在上一步；已有历史截图不覆盖。截图定位测试位于 tests/rpa/test_report_screenshot_focus.py。
* 处理记录：展示已有接收、解析、回复、任务状态和真实上报记录，不生成虚构操作历史。

未配置供应商只显示邮件核对、回复审核和处理记录，保留原有时间分析结果及失败重试。
邮箱只读权限下不开放修改操作。

保存边界
--------

* 修正识别结果只作用于当前邮件，不改变供应商规则。
* 按既有接口约定，保存识别结果会重新匹配线路并清除人工绑定。
* 保存结果或绑定不会自动覆盖已生成的填报任务；页面提示人工重新生成并核对。
* 修改时间不会重新判定历史回复场景，也不会自动发送回复。
* 填报未保存时不能确认或上报；收起或切换填报任务时提示放弃未保存内容。
* 回复和上报独立处理。发送回复不会移除其他待办。

附件核对
--------

原邮件区域按文件名列出附件，隐藏存储时附加的随机前缀。点击预览后在左侧显示附件，
右侧识别结果保留；可切换其他附件或返回邮件正文，也可以下载原文件。

* CSV / TSV / TXT / LOG：识别原文件编码，表格按字符串展示，保留编号前导零。
* XLSX：可选择工作表，保留文本编号及常见补零格式；公式仅展示原文，不执行计算。
* DOCX：展示正文和表格；原始排版及图片通过下载核对。
* PDF：通过浏览器内置阅读器预览；PNG / JPEG / GIF / WebP / BMP 直接展示图片。
* 旧版 DOC / XLS 等未支持的格式提示下载，不调用外部转换服务或 FastGPT。

预览接口：GET /api/cutover/emails/<email_records_id>/attachments/<attachment_index>/preview。
附件索引对应邮件详情 attachments / attachment_urls 数组，继承邮件邮箱的只读授权。
新接口需要后端加载更新后的 api_server.py 与 access_http.py。

原件不修改。文件限 20 MB，文本限 2 MB；预览最多每表 500 行、64 列、20 个工作表，
总文本 30 万字符，超过预览范围会明确提示下载完整文件。
Office 压缩包展开大小受限，禁止 DTD / 实体声明、外部链接加载和公式执行。

附件测试分别位于 tests/mail/test_attachment_preview.py、
tests/api/test_attachment_preview_api.py 和 tests/ui/test_cutover_attachment_preview_ui.py，
覆盖编码、编号前导零、格式与体积限制、邮箱授权、损坏文件、切换时的过期响应及下载。
PDF 使用完整浏览器的内置阅读器；本机视觉复核可设置 UI_BROWSER_CHANNEL=chrome。
