割接邮件及关联数据删除
====================

范围与入口
----------

割接任务列表按邮件聚合。一条邮件可能包含客户线路与骨干线路两个任务，
本功能删除整条邮件及其所有子任务，不是只删除其中一种线路任务。
列表操作列和详情顶部均提供删除入口，确认框展示邮件主题与永久删除范围。

删除内容：

* email_records：正文、附件引用、提取与线路匹配结果、场景、分析结果、回复草稿与回复记录。
* 该邮件的 ticket_records、cutover_tasks、cutover_reports、mail_ai_jobs。
* supplier_draft_samples 中的本邮件关联；供应商草稿中的来源引用及可溯源的原邮件样本副本。
* 本地专属 EML、附件、客户线路 Excel、上报截图及可确认归属的历史正文截图。

保留内容：

* 供应商正式配置、共享供应商草稿的配置规则和其它邮件样本、线路主数据、邮箱与系统配置。
* 其它邮件引用的共享文件。没有足够归属信息的同 UID 历史文件不得跨邮箱误删。
* 原始邮箱中的邮件及外部综调记录。本接口不调用 IMAP 删除或外部撤单。
* 最小删除标记（邮箱、UID、原记录 ID、状态与时间），用于防止监听器再次导入同一封邮件。
  标记不保存正文、分析或回复；文件清理完成后清空临时清理清单。
  删除标记的邮箱地址统一去除首尾空白并忽略大小写。

接口与失败处理
--------------

``DELETE /api/cutover/emails/{email_records_id}`` 使用既有 API Key 认证。
成功返回 ``success: true``，data 包含 email_records_id 与 deleted。
已完成删除的同一记录重复请求返回成功；没有记录也没有删除标记时返回 404。

任务正在上报、上报记录 pending/running、AI 运行中、邮件 forwarding 或回复 sending 时返回 409。
同一邮件的同步 API 修改与删除互斥，避免编辑/生成文件与删除同时进行。
FastGPT 转发不跨网络请求持有 API 锁，避免阻塞其同步回调；转发由数据库原子状态抢占保护。

清理分两阶段：

1. 在数据库写事务中复查活跃处理、收集文件归属，登记 pending_cleanup；暂保留邮件行。
2. 清理专属文件，成功后事务删除关联记录及邮件，将标记改为 deleted 并清空清理清单。

文件清理失败或数据库提交失败返回 500，邮件暂留列表，可再次点击删除继续清理。
删除标记存在时阻止新的生成、解析、回复和迟到结果写入；子记录创建需原子验证父记录仍存在。
监听处理中固定使用原邮件记录 ID，删除后不会退回按 UID 匹配到另一邮箱的邮件。
清理限制在明确的数据/图片根目录内，拒绝路径穿越和符号链接越界。

历史数据兼容
------------

已配置与未配置供应商邮件使用同一清理流程。没有子任务、工单、报告、AI 作业、
草稿关联或对应本地文件时，跳过缺失项并继续删除其余数据。
附件、上报结果及草稿中的可选字段为空、缺省或格式不完整时，不阻塞邮件删除；
可识别的有效文件引用仍会正常清理或纳入共享文件保护。
来源草稿整体 JSON 已损坏或不是对象时，清空其无效生成内容并恢复 collecting，
防止已删除邮件正文仍残留在不可解析的草稿中；保留候选、其它样本及正式供应商配置。

历史容器或旧部署保存的 ``/app/data/mail_store/...``、``.../data/rpa/artifacts/...``
等已知存储路径，按当前 DATA_DIR 重新定位。绝不按旧绝对路径删除其它目录中的文件。
其它邮件的异常外部文件引用不阻塞本邮件删除；本邮件已不存在的旧外部引用跳过并记日志。
本邮件确实存在且无法归属到数据目录的外部文件仍拒绝删除，避免误删。
新上报的 screenshot_path 与 operation_log 统一保存相对于 DATA_DIR 的路径。

页面行为
--------

* 取消确认不发送删除请求；处理中禁用重复操作。
* 失败展示接口原因并保留当前列表/详情。
* 列表删除成功刷新列表与顶部统计，末页为空时回到前一页。
* 详情删除成功替换当前历史记录并返回割接列表。
* 仅支持 1280px 及以上桌面布局。

验证
----

使用隔离数据库、临时文件目录和虚构邮件，未删除实际业务邮件或发送真实回复。
相关用例位于 tests/api/test_cutover_deletion_api.py、tests/storage/test_mail_deletion_guards.py、
tests/api/test_mail_operation_guard.py 和 tests/ui/test_cutover_deletion_ui.py。
桌面截图位于 ``.qa/cutover-deletion/``。

删除 API 与文件清理包含 28 项用例；数据库写入保护 12 项、同步操作保护 5 项，
另有监听删除竞态用例及既有割接、回复、草稿等回归。真实浏览器的 4 项删除流程用例通过，
覆盖取消、成功、失败、重复操作、详情返回和末页回退，并检查 1280px 与 1440px 布局。

测试需从临时工作目录运行，并设置 PYTHONPATH 为项目路径，避免模块全局数据库初始化触及工作库。
